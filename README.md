# 🛡️ SafeRoute Guard (Offline SMS Edition)

A student safety mobile app that protects students during school hours until they reach home safely. Works **100% without internet** using cellular SIM SMS, hardware GPS satellites, and phone accelerometer sensors.

## Core Capabilities
- **Zero-Internet SMS Alerts:** Sends automatic SMS with Google Maps GPS coordinates via SIM card.
- **School-to-Home Geofence:** Automatically texts parents when the student reaches school, leaves school, and arrives home safely.
- **Fight & Struggle Detection:** Detects violent shaking/impacts using the phone's accelerometer and alerts parents if not canceled within 10 seconds.
- **One-Tap Panic & Fight Buttons:** Instant manual SOS, fight/bullying reporting, loud deterrent siren, and manual safe home check-in.

## How to Build Your Installable `.apk` File
1. Open `www/js/config.js` and enter the parent's phone number and School/Home coordinates.
2. Commit your changes to the `main` branch.
3. Click the **Actions** tab at the top of this GitHub repository.
4. Open the latest **Build Offline Android APK** run and download **SafeRoute-Guard-Offline-APK** under **Artifacts**.
